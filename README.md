# TO-DO-APP
This To-Do List application is a stylish, interactive web tool built using HTML, CSS, and Vanilla JavaScript, offering a complete CRUD (Create, Read, Update, Delete) experience with a modern 3D animated user interface.

Key Features:

Add Tasks: Users can seamlessly create new to-do items using a dynamic input field with smooth animations.

Edit Tasks: Existing tasks can be edited directly from the task list, updating instantly with real-time feedback.

Delete Tasks: Tasks can be removed individually with a clean transition animation.

Task View: All tasks are displayed in a beautifully designed 3D container that rotates and animates with user interaction.

3D Animations: Eye-catching CSS 3D effects, shadows, and transitions enhance the visual appeal and interactivity.

Responsive Design: Fully optimized for mobile, tablet, and desktop views.

Technologies Used:

HTML5 – For structured markup of tasks and layout.

CSS3 – Advanced 3D transformations, transitions, and animations.

JavaScript (ES6) – Logic for handling all CRUD operations dynamically in the browser.

Use Case:

Perfect for users who want a modern, animated experience to manage their daily tasks efficiently with an engaging UI.
